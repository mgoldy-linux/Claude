# SA-48124 — Vendor Invoice Report: Additional Charges — Update 07/28/2026

## Status: Built and working in the test environment (P21Play); ready for Production deployment

### What was done
The report has been updated so it now shows the **additional invoice charges** (drop charge, pallet, driver assist, etc.) that previously never appeared — only freight did.

1. **Added a small custom data source** that pulls each invoice's extra charges (charge description + amount) from the EDI data, with the plain-English charge name. This is a self-contained add-on; the standard P21 report data was not modified.
2. **Added an "Additional Charges" section** to the report (a subreport in the invoice footer). For any invoice that has extra charges, it now lists them itemized — e.g., "Drop Charge … 41.56."
3. **Corrected the invoice total.** Previously the printed total left the extra charges out, so it came up short. The report now shows an **"Invoice Total (incl. charges)"** line that reflects the true amount the supplier billed (P21's stored invoice amount).
4. **Clean handling when there are no extra charges** — invoices with only freight (or nothing extra) print exactly as before, with no empty section.

The custom data source has been deployed to **both the test (Play) and Production databases**, so it's ready wherever the report runs.

### Verified in the test environment (P21Play)
- **Invoice 26172056** (has a drop charge): now shows **"Drop Charge … 41.56"** and a corrected **Invoice Total of 597.16** — previously it printed 555.60 and no drop charge.
- **Invoice 26171989** (freight only, no extra charges): prints normally with its freight, **no** Additional Charges section, total unchanged — confirms nothing broke for the normal case.
