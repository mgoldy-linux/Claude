## Why a TVF, not a view
The `.srd`'s `<user_id>` portal-substitution placeholder needs a real parameter — a plain `VIEW`
can't accept it (P21 substitutes it as text into the `.srd`'s own SQL at request time, not inside
a called object). See `feedback_p21_portal_datawindow_sql_simple.md` for the general rule this
created, and the Deploy Guide for the full reasoning + performance history (1:30 → 42s).
